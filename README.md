## Featured work

### KLIGHTTEN AI

A personal assistant for Linux desktop and Android that combines local GGUF models with optional online APIs. The project explores Flutter, llama.cpp, API routing, and offline-first AI.

`Flutter` `Dart` `llama.cpp` `GGUF` `REST APIs` · **In active development**

### KLIGHTTEN MEDIA

A Linux desktop media application for online and local playback, with anime integration, custom themes, background playback, and keyboard media controls.

`Python` `PyQt6` `mpv` `ani-cli` · **Working desktop build**

### KLIGHT Panel

A lightweight custom panel designed for Linux Mint XFCE, featuring system controls, media integration, accessibility tools, and a compact Klightten visual identity.

`Python` `GTK 3` `Linux` · **Working prototype**
